# Pinned tunnel-binary releases. This file is the single source of truth for
# both readers: scripts/fetch-cloudflared.sh (build time, vendors the binary
# into the desktop bundle) and package tunnelget (runtime, downloads it onto a
# machine that did not get one in its package). Two copies of a checksum is
# two chances to raise one of them and forget the other.
#
# Raising the pin: change the version line, replace every checksum with the
# digest the vendor publishes for the new tag, refresh
# third_party/cloudflared/LICENSE if upstream changed it, and re-run the
# script for every target.
#
#   base    <binary> <url prefix, up to but not including the version>
#   version <binary> <release tag>
#   asset   <binary> <goos/goarch> <published file name> <tgz|raw> <sha256>
#
# The sha256 is of the published asset as downloaded. For tgz assets that is
# the archive, not the binary inside it.
